# TASK 1 – 2D Residential Floor Plan

## Project
2D Drafting – Residential House Floor Plan

## Description
This project contains a 2D floor plan of a residential house created as part of the AutoCAD drafting task.

## Included Features
- Minimum 2 bedrooms
- Living room
- Kitchen
- Bathroom
- Furniture layout
- Room labels
- Dimensions
- Wall thickness
- Architectural annotations

## Files
- Residential_Floor_Plan.pdf – Final PDF drawing
- Residential_Floor_Plan.dxf – Editable CAD source
- Residential_Floor_Plan.dwg – AutoCAD source file
- preview.png – Drawing preview

## Software
AutoCAD
